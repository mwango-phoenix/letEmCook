# FitKit
A workout planner and tracker to help you achieve your fitness goals and plan routines efficiently.

[View App Blueprint](https://www.behance.net/gallery/230345317/FitKit)

  
- ## Features
- Main Page: view of recently added recipes and basic categories
- Random Page: generate a random recipe to try
- Categories Page: display of all categories to choose from
- All Recipes Page: display all recipes in database from most to least recent
- Submit Page: page to submit a new recipe to the database
- Map (in progress): clickable map to show you recipes froma certain region

## Technologies
- `Express`
- `MongoDB`
- `Node.js`

## Motivation and Process
Cooking and baking are a huge passion of mine and I love to experiment with food.  This is a collection of all my recipes that I have built up over time as well as new recipes I have yet to discover.
